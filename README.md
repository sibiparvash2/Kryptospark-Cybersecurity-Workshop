Curriculum, lab guides, and recordings from a 2-day international cybersecurity workshop conducted for Kryptospark, Philippines


# Kryptospark International Cybersecurity Workshop 🌐🛡️

**Role:** Lead Trainer  
**Event:** 2-Day Cybersecurity & Ethical Hacking Workshop (Philippines)  
**Topics Covered:** Cyber Fundamentals, Networking, OSINT, and Practical Virtual Labs.

## 📝 Overview
This repository contains the curriculum, practical lab instructions, and session recordings for an international workshop I conducted at Kryptospark. The sessions were designed to take participants from cybersecurity fundamentals through to hands-on penetration testing techniques using Kali Linux.

## 📅 Workshop Curriculum

### Day 1: Foundations & Networking
* **Introduction to Cybersecurity:** The CIA Triad (Confidentiality, Integrity, Availability) and the "Hat" Method of classifying hackers[cite: 4].
* **Networking Fundamentals:** IP Addressing, TCP vs. UDP, Common Ports, and the OSI Model[cite: 5].
* **Common Protocols:** Deep dive into DNS, DHCP, SSH, HTTP/HTTPS, and NAT[cite: 1].
* **Reconnaissance & OSINT:** Passive vs. Active reconnaissance, utilizing WHOIS data, and building target profiles[cite: 5].

### Day 2: Practical Labs & Security Tools
* **Hands-On Security Lab Setup:** Virtualization using Oracle VM VirtualBox and deploying Kali Linux as an attack platform[cite: 6].
* **Linux Basics:** Command-Line Interface navigation and core commands (`ls`, `cd`, `pwd`, `cp`)[cite: 5].
* **Security Tools:** Practical demonstrations of Wireshark for packet sniffing, Nmap for network scanning, and Metasploit for exploitation[cite: 3, 7].
* **Web Application Security:** Overview of the OWASP Top 10, Broken Access Control, Injection, and Secure Password Storage (Hashing & Salting)[cite: 2].

## 💻 Practical Lab: Kali Linux Setup
*Detailed instructions on configuring the lab environment.*
1. **VirtualBox Installation:** Setting up the hypervisor.
2. **Kali Linux Deployment:** Importing the custom VM image and configuring network adapters (Bridge/NAT)[cite: 6].
3. **Basic CLI Navigation:** Understanding the Linux file structure (`/root`, `/home`, `/bin`) and executing foundational commands[cite: 5].
